ℹ️ About Page Load Timings in XLT

Real-user and real-browser frontend performance metrics

The individual timings for a page load are captured directly from the browser window using the W3C Navigation Timing API. All timing values are measured relative to the start of the page load.

Note that these timings are recorded when using XltChromeDriver or XltFirefoxDriver to run real browser automation. These specialized WebDriver implementations install a telemetry extension into the browser instance to measure DOM Interactive, DOM Complete, First Paint, and full document load events.

Configuration Example to enable client performance in browser tests: 
xlt.webDriver.chrome_clientperformance.pathToDriverServer = /path/to/chromedriver
xlt.webDriver.chrome_clientperformance.browser = chrome
xlt.clientperformance.recording = true
