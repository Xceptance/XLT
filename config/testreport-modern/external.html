About External Data Ingestion in XLT

Correlating backend server and infrastructure metrics with client-side user experience

XLT provides built-in mechanisms to ingest external time-series data collected during a test run from APM platforms (e.g. Dynatrace, Datadog, Prometheus) or database performance monitors.

When configured, external data files placed in the test results directory are automatically parsed, charted, and correlated against client request rates, response times, and error spikes.

How to supply external metric data to XLT report generator:

Configure external data parsers in externaldataconfig.xml and place CSV/log files in the test results folder prior to running create_report.
